## Project Overview

Prime Ops Congo is a professional operations and business support website. The website provides information about the company, its services and how potential clients can make enquiries.

The company focuses on mining, logistics and engineering services in the Democratic Republic of Congo and South Africa.

## Website Goals and Objectives

The main goals of the website are:

- Introduce Prime Ops Congo to potential clients.
- Provide information about the company.
- Display the services offered.
- Allow visitors to make enquiries.
- Provide contact information.
- Create a professional online presence.

The website contains the following pages:

2. About Us

4. Gallery
